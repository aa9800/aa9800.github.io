Privacy policy

Last updated: 2026-11-26

This OAuth client is used only by its owner, through rclone running on the owner's own computers, to read and write files in the owner's own Google Drive.

  • No data is collected, stored, or shared by this client or by any server operated for it.
  • Access tokens stay in the rclone configuration file on the owner's computers.
  • Google user data is not transferred to any third party.

Questions: open an issue at github.com/aa9800/aa9800.github.io.
